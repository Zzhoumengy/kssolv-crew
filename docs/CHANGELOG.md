# 更新记录

## 0.2.1 · 真实材料计算验证与 DeepSeek 限额支持

- 完成 Si / mp-149 的真实 MP、DeepSeek、MATLAB SCF 和 10 段 NSCF 测试。
- 修正用户 KSSOLV3 的行向量晶格约定、eband 数值导出、统一 SCF 费米参考及 MATLAB Engine StringIO 日志接口。
- 记录 SCF 收敛标志、迭代数、残差、能量和每段原始数值；参数收敛状态单独保留。
- 新增 DeepSeek 官方接口的 CrewAI LLM 适配器：每任务硬限制 2 次 HTTP 请求、关闭思考、限制输出、不自动重试、密钥使用私有属性。
- 修正报告措辞，区分本次数值 SCF 收敛与尚未验证的截断能/k 网格收敛。

## 0.2.0 · 原生桌面界面

- 新增 Tk 桌面窗口，直接调用现有 worker，不启动 HTTP 服务，不依赖浏览器。
- 默认 start.cmd 改为打开桌面版；原网页版移到 start-web.cmd，stop.cmd 仅控制可选 Web 服务。
- 支持材料任务、双密钥、MP ID、模式、SCF/k 路径参数、模型及软件目录输入；密钥不持久化。
- 新增阶段状态、历史任务、报告、MATLAB 日志和 PNG 能带图预览，以及打开结果目录、停止任务与关闭确认。
- 使用后台线程协调独立计算进程，避免 GUI 被 SCF/网络调用阻塞；保存桌面任务标识，防止可选 Web 服务误标记桌面任务中断。
- MATLAB 适配器及原 SCF/eband 调用顺序未改变。
- 修复 Windows 状态文件读取与替换之间的短暂共享冲突：使用独立临时文件并重试原子替换，避免桌面刷新导致任务提前失败。

## 0.1.2 · 网站启动修复

- 默认启动改为独立后台进程，启动窗口退出后仍保持网页服务；确认健康检查成功后才打开浏览器。
- 自动避开占用端口，识别并复用本项目已有服务，避免盲目打开固定网址。
- 新增 stop.cmd 和需私有控制令牌的优雅停止接口；服务状态与日志位于不参与发布的 .runtime。
- 教程明确区分本机软件地址和公共互联网网站，补充拒绝连接时的恢复办法。
