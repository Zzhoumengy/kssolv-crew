## 尚需用户环境验证

用户的 `kssolv-3o-dev` 未提供，不能验证其中私有版本 API。项目只按给定脚本调用 `KSSOLV.startup/openProject`、`pseudopotential.PpType`、`scf`、`options.NSCF`、`eband`。`.m` 构造使用 `Crystal('supercell', C, 'atomlist', atomlist, 'xyzlist', xyz)`；需确认该版本构造函数及 C 列向量约定。若版本不同，局部修改 convert.py 和 MATLAB 适配层即可，Flow 无需改动。

适配器假定 `H.rho` 为数值数组，`eband` 创建包含 line 对象的 MATLAB figure；否则校验失败并保留日志。输出图对象数据并非自动认证的本征值格式。KSSOLV 内部 figure 可能不只包含能带，需核对实际 PNG/FIG；不从图形拟合带隙。

示例参数 ecut=20、2×2×2 网格、nbnd=14 不保证 Si 或其他材料收敛。本项目未接入用户版本的收敛返回字段；即使真实调用正常返回，也会明确写 `convergence_verified=false`。请人工核实 SCF 日志、电子数、赝势、单位、路径和计算参数收敛。
